# gitlgbt Infrastructure
this is an deploy file for gitlgbt

install git and clone this repo
```bash
sudo apt update && sudo apt install -y git
git clone https://github.com/gitlgbt/infa.git
cd infa
```

install git.lgbt
```bash
chmod +x update.sh
chmod +x install.sh
./install.sh
```

update git.lgbt
```bash
./update.sh
```
